Seit 1998 arbeite ich mit Webtechnolgien und versuche standig dazu zu lernen. Neben meiner Festanstellung nutze ich meine Fähigkeiten um Vereinen, Initiativen und kleine Unternehmen zu unterstützen. Dabei mache ich auch manchmal Ausflüge in die Welt des Print.

Ich habe anfangs an allen Enden mal gearbeitet, aber mich am Ende auf das direkte Frontend, also alles womit User interagieren, spezialisiert. Darum kenne ich auch die anderen Bereiche, die es für ein Webprojekt benötigt. Ich kann das große Ganze sehen und zwischen den verschiedenen Beteiligten vermitteln.

* HTML, CSS, SVG
* Web Standards
* Responsive Webdesign
* Accessibility
* Interne Accessibility Audits
* grav / WordPress / PHP
* Web Performance
* Vanilla JavaScript
* Web Components
* Information Architecture
